
# CNNs for Smart Waste Management ♻️

This repository contains the technical presentation for a university project focused on the mathematical foundations of Convolutional Neural Networks (CNNs). The project explores linear algebra, gradient descent, and backpropagation, applying deep learning architectures (convolutional layers, ReLU/Softmax) to sustainable waste classification.
